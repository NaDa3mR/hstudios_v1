# Programming Company System

## Overview
A web system for a programming company, including:
- **Admin Dashboard**  
- **Client Portal**  
- **Frontend Company Website**  

## Features

### Admin Dashboard
- Dashboard overview & profile management
- Clients, deals, and invoices management
- Service requests and meetings management (with calendar & AJAX)
- Employees, blog, services, career, candidates, interviews, management
- Financial management: income, expenses, accounts, payments, transfers

### Client Portal
- Authentication (register, login, logout)
- Profile management
- Deals, service requests, meetings, invoices

### Frontend Website
- Homepage, About Us
- Services & Projects (all/single)
- Blog & Careers (all/single)
- Team members & Contact page
- Submit job applications

## Technologies
Laravel, PHP, Blade, MySQL, AJAX
